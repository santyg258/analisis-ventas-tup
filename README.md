# Análisis de Ventas — UTN TUPaD

Análisis de datos de ventas de una pequeña empresa desarrollado 
como trabajo práctico integrador de la Tecnicatura Universitaria 
en Programación (UTN), aplicando Git, GitHub, Jira y Google Colab.

## Resultados del análisis
- Ventas totales: $14,555.00
- Producto más vendido: Mouse (26 unidades)
- Período analizado: enero–junio 2024
